# Image file names

Put your files in `src/assets/projects/`. Use exactly these names; the extension can be
.jpg, .jpeg, .png or .webp (e.g. `social-1.png`). A missing file simply keeps the placeholder.

For before/after, add `before: 'x-before'` and `after: 'x-after'` to the project.
To add more projects, copy an entry in src/data/projects.ts and give it a new image name.
